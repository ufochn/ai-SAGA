## 一、可直接粘贴的系统提示词

```
你是 AI-SAGA 互动小说生成引擎。请严格依据用户的设定与剧情上下文，撰写【下一段】小说正文。

【用户设定】(JSON)
{"settings": {"location": "江南水乡", "era": "清末", "player_name": "沈砚", "player_gender": "男", "partner_name": "阿箬", "partner_gender": "女", "partner_traits": "聪慧果敢", "language": "中文"}, "user_input": "推开那扇雕花木门", "user_input_counter": 2}

【上一段剧情】(若为空字符串，则为全新故事的开篇)
雨丝斜斜地落在青石板上。沈砚站在巷口，伞沿的雨水顺着指尖滴落，他回头望了一眼来路——那盏灯笼还亮着。阿箬拎着裙角快步追上来，压低声音说："前面就是那座宅子了，门匾上的字被雨水冲得模糊，但轮廓像是'听雨轩'。"两人对视一眼，都知道这一趟并不寻常。

【本轮用户输入】
推开那扇雕花木门
（这是第 2 轮输入）

【输出要求 —— 必须严格遵守】
1. 只输出小说正文本身：从正文第一个字开始写，不要任何开场白、说明或前缀。
2. 严禁输出 JSON、代码块、Markdown、标题、序号、注释或任何解释性文字。
3. 严禁在正文末尾追加任何变量、分隔符、标签或结构信息——正文到此为止，什么都不加。
4. 正文须与「上一段剧情」自然衔接（若存在），并围绕「本轮用户输入」推进剧情。
5. 篇幅控制在 4000 token 以内，内容充实、有画面感。
6. 全程使用「用户设定」中 language 字段指定的语言撰写。
```

## 二、上面各变量的解析来源对照

| 提示词里的占位符 | 示例中替换成的真实值 | 来源 |
|---|---|---|
| `{{#<Code①>.clean_prompt#}}` | `{"settings": {...}, "user_input": "...", "user_input_counter": 2}` | Code① 用 `json.dumps(ensure_ascii=False)` 生成的 JSON 字符串 |
| `{{#<Start>.previous_story#}}` | 「雨丝斜斜地落在青石板上……这一趟并不寻常。」 | 上一段正文（服务器从 DB 取） |
| `{{#<Start>.user_input#}}` | `推开那扇雕花木门` | 本轮用户输入 |
| `{{#<Start>.user_input_counter#}}` | `2` | 轮次计数 |
| `{{#<Start>.max_tokens#}}` | `4000` | 服务端 DIFY_MAX_TOKENS |

> 注意 `clean_prompt` 是**带引号、带转义的 JSON 字符串**，它会整段原样出现在提示词里（模型是"读"这段 JSON 设定），这就是上一条消息说的"输入 JSON、输出纯文本"。

## 三、合规输出的样子（预期样例）

下面是一段**应该通过**的模型输出（纯文本、无任何标记、无结尾附加信息）：

```
沈砚的手触上那扇雕花木门，指尖在冰冷的铜环上顿了顿。雨水顺着屋檐汇成细线，在门楣上淌出一道亮痕。他侧过头，与阿箬交换了一个眼神——后者微微颔首，将伞往他那边倾了倾。

"吱呀"一声，木门向内推开。扑面而来的不是腐朽的气息，而是一阵若有若无的檀香，混着陈旧书卷的味道。门内是一条幽长的回廊，两侧挂着的灯笼不知何时已经燃起，暖黄的光晕在雨夜里显得格外安宁，却又透着一丝说不出的诡异。

沈砚跨过门槛，靴底在青石地面上落下第一声轻响。回廊尽头，一扇半掩的房门前，站着个背对着他们的身影，衣角被穿堂风轻轻拂动。
```

**检查点**：
- ✅ 从正文第一个字开始，没有"好的""以下是正文"之类开场白；
- ✅ 全篇是纯文本，没有 `#`、`**`、```` ``` ````、`{` `}`、`<...>` 等标记；
- ✅ 结尾就是最后一个句号，后面没有任何变量/JSON/标签/分隔符。

## 四、测试时的核对清单

- [ ] 把「一」整段贴进 Dify LLM 节点（系统提示词），模型选 OpenAI 系列；
- [ ] 观察**流式输出**：正文是否连续流畅、首段是否被 450 字审核切断（测试时可直接看全文）；
- [ ] 输出是否**纯文本**（没有任何 Markdown/JSON/XML 符号）；
- [ ] 结尾是否干净（无 `<<<META>>>`、无 `{"...":...}`、无补充说明）；
- [ ] 正文是否与「上一段剧情」衔接、是否回应「本轮用户输入」；
- [ ] 语言是否与 `language` 一致（示例为中文）；
- [ ] 若模型偶尔输出违规内容（如带 Markdown 或末尾加注释），先尝试**调低 temperature（如 0.6–0.7）**或加强第 2、3 条措辞，不要改成让模型输出结构化内容（会破坏流式）。

## 五、顺带测试 Code②（推导变量）—— 用 LLM① 的合规输出喂它

Code② 的 Python 直接放进 Dify Code 节点，用 LLM① 的 `text` 测试：

```python
import re

def main(text: str, user_input: str, language: str) -> dict:
    t = (text or "").strip()

    parts = re.split(r"[。！？!?；;\n]", t)
    first = next((p.strip() for p in parts if p.strip()), "")
    title = (first[:15]) or "新的一章"

    summary = (t[:40] + ("…" if len(t) > 40 else "")) if t else ""

    goal = (user_input or "").strip() or "当前目标"
    choice_1 = f"继续推进：{goal}"
    choice_2 = f"留意线索：围绕“{title}”展开调查"
    choice_3 = "稍作停留，观察环境并调整计划"

    return {
        "title": title,
        "summary": summary,
        "choice_1": choice_1,
        "choice_2": choice_2,
        "choice_3": choice_3,
    }
```
